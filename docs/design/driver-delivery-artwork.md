# Driver delivery artwork

Generated with the built-in image generator. Its interface does not expose or confirm an Image 2.5 model selection.

- `public/assets/generated/driver-delivery-side-v1.png`: transparent side-on driver, target right, short shaft rising above right-hand hosel, black carbon crown and satin titanium face, soft studio lighting; no ball, text, branding, ground or metric overlays.
- `public/assets/generated/driver-delivery-top-v1.png`: matching overhead crown view, target right, striking face along right edge, short shaft toward top; same materials, transparency and exclusions.

These are illustrative unbranded drivers, not product-identification photographs. Used only for the Driver family in the Club metrics side and top cards. Balls, angles, lines and selected-shot values remain rendered by the existing UI. Other club-family illustrations are unchanged.

## Matching iron assets

Built-in generator, same transparent studio finish. Generic mid-iron illustration, not a particular branded model or a measurement of club loft.

- `iron-delivery-side-v1.png`: true toe-end side profile, thin solid silver head with right-facing lofted face, chrome shaft and black ferrule; no labels, ball or branding. First malformed L-shaped draft rejected and not copied into the project.
- `iron-delivery-top-v1.png`: overhead address view, narrow silver topline and grooved face toward the right, hosel and short shaft extending up; transparent background, no overlays.

Both are used for numbered iron club types in the existing delivery diagrams.

Production uses WebP derivatives with the same dimensions and alpha transparency. PNG files are retained as generated masters.
