## Specific acceptance closures in the final pass

- Populated goals: actual rendered component with increasing, decreasing and zero-target QA fixtures; no account writes. Light 390px and dark/reduced-motion 320px with 20px root inspected. Current and Target labels prevent an inverted objective looking like a completion ratio. Open evidence remains readable; controls measure at least 44px, with no horizontal overflow.
- Screen awake: pending acquisition is serialized; a lock arriving after the activity exits or hides is released; an already-released lock is not retained. Unsupported/declined requests leave the activity usable. Hook tests verify lifecycle, not physical battery or haptic response.
- Course Twin: mobile render suspension preserves the mounted scene, playback position and round state. Context loss permits native Three.js restoration and shows an optional 2D action. Pending shots/saves retain the existing display-switch guard. The original renderer and default 3D selection remain in place.

## Evidence limits and release status

The following are explicit observation boundaries, not an unbounded implementation backlog:

- Physical iPhone safe-area/keyboard behavior, outdoor legibility, assistive-technology use, frame pacing, heat and battery consumption have not been measured. WebKit, enlarged-text, reduced-motion, viewport and draw-counter checks cover their stated browser cases.
- Personal account writes were intercepted during visual QA. Existing domain/server-action and isolated operation tests cover mutations; this document does not claim a new successful production round, import, speed session or shot-review write.
- Available courses can have estimated outlines, coarse terrain and missing hazards. The app labels those conditions and withholds unsupported advice. Improving or surveying source mapping is separate from redesigning the mobile experience.
- A passing production build is not a deployed release or an authenticated production visual check. Use the associated pull request and deployment status for publication evidence.
