## Recovery API

Read local Next 16.3 guides `03-architecture/accessibility.md`, `01-app/01-getting-started/10-error-handling.md` and `01-app/03-api-reference/03-file-conventions/error.md`. `retry()` refetches and re-renders a failed segment; `reset()` only clears boundary state. Account and public-share recovery now request the former. A new page-group-only `account-route-error.tsx` supplies consistent app-width recovery without changing global components.
