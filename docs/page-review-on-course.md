# On-course page review

18 October 2026. Scope: the 18 actual page routes under courses, course-records, course-twins, play, rounds and simulator-lab. This review preserves full-width app content, green/cream tokens, saved records, navigation and the existing geometry/game behavior. No database, schema, security, authentication, package or service changes were made by this stream.

Read `AGENTS.md`, the ForeKingHell page-polish skill and the installed Next.js error/loading and server/client guidance. The installed error API uses `retry`; all new route boundaries call that supplied callback.
